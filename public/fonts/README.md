# Web fonts

Drop licensed font files here with these exact names. The CSS in `src/app/globals.css`
tries the locally installed font first, then these files, then the free fallback fonts.

- `DharmaGothicM-HeavyItalic.woff2` (display headlines)
- `DharmaGothicM-Heavy.woff2` (date cards)
- `Avenir-Roman.woff2` (body)
- `Avenir-Heavy.woff2` (labels, buttons)

Dharma Gothic M is sold by Dharma Type (Fontspring). Avenir is a Monotype/Linotype font.
Without the files, Saira Extra Condensed (display) and Nunito Sans (body) from Google Fonts are used.
